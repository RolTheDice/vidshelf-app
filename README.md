# VidShelf

내 PC 속 영상을 **파일은 그대로 둔 채** 품번·배우·제작사별로 정리해서 보는 개인용 Windows 프로그램.

- 파일 이름에서 품번(예: `ABC-123`)을 읽는다
- **r18.dev**(DMM 작품 정보를 공개 JSON으로 제공)에서 배우·제작사·레이블·시리즈·감독·장르·발매일·재생시간·제목과 정확한 표지 주소를 가져온다 (로그인·키 필요 없음)
  - 장르는 정해진 표로 한국어로 바꾸고, 배우 이름은 일본어 읽는 법을 한글로 바꾼다 (예: やまぎしあいか → 야마기시 아이카)
  - 처음 보는 배우는 **품번기**(poomki.net)의 한국어 이름과 맞춰 보고, 한 번 정한 이름은 기억한다
- DMM에서 표지를 찾아 저장한다 (ShowCover v1.1의 레이블 대응표 + 찾은 주소 형태를 레이블별로 기억해서 다음부터 바로 찾음)
- 왼쪽 큰 창에 표지와 정보, 오른쪽에 파일 목록
- **최근 추가**: 최근 30일(설정에서 변경) 안에 들어온 영상 중 아직 안 본 것. 재생 횟수가 1회가 되면 빠진다
- 배우별 / 제작사별 / 품번별 / 레이블별 / 시리즈별 / 장르별 / 즐겨찾기 / 미분류 / 중복 품번 보기
- 별점, 즐겨찾기, 메모, 재생 횟수, 정보 직접 수정, 표지 직접 지정
- **내장 플레이어**: 표지 창 자리에서 바로 재생, 전체 화면, 이어 보기, 배속, 이전/다음, 셔플·반복
- **재생목록**: 이름 붙인 재생목록 여러 개, 끌어서 순서 바꾸기, 연속 재생
- **여러 개 선택**(Ctrl·Shift) 후 재생 / 재생목록에 추가 / 삭제
- **삭제**: 기본은 휴지통, 원하면 완전 삭제 (표지 jpg 함께 지우기 선택)
- **영상 파일은 삭제를 누를 때 말고는 절대 옮기거나 바꾸지 않는다.** 분류는 프로그램 안에서만 한다.

## 설치 (Windows)

1. [Releases](https://github.com/RolTheDice/vidshelf-app/releases/latest) 페이지의 **Assets**에서 `VidShelf-Setup-….exe`를 받는다
2. 받은 파일을 실행한다. Windows가 **"Windows의 PC 보호"** 창을 띄우면 **[추가 정보] → [실행]** (코드 서명을 하지 않은 개인 프로젝트라서 나오는 경고)
3. 설치가 끝나면 바탕화면·시작 메뉴의 **VidShelf**로 켠다

새 버전은 같은 방법으로 받아서 그 위에 설치하면 된다. 정리한 정보(`%APPDATA%\VidShelf`)는 지워지지 않는다.

## 소스로 설치·자동 업데이트 (선택)

설치 파일 대신 소스를 받아 두면 GitHub Desktop에서 **[Pull origin]만 누르면 자동으로 업데이트**된다. 토큰이 필요 없다.

처음 한 번만:
1. (설치 파일로 깔았다면) **설정 → 앱 → VidShelf → 제거**. 정리한 정보는 `%APPDATA%\VidShelf`에 그대로 남는다.
2. [Node.js LTS](https://nodejs.org/)와 [GitHub Desktop](https://desktop.github.com/) 설치
3. GitHub Desktop에서 **File → Clone repository → URL**에 `https://github.com/RolTheDice/vidshelf-app` → **Repository → Show in Explorer**
4. 폴더 안의 **`VidShelf 설치.cmd`** 더블클릭 → 구성 요소 설치·빌드 → 바탕화면에 **VidShelf** 아이콘이 생기고 프로그램이 켜진다

그다음부터:
- GitHub Desktop에서 **[Fetch origin] → [Pull origin]** → "VidShelf 업데이트" 창이 잠깐 떠서 빌드하고, 켜져 있던 VidShelf가 새 버전으로 다시 켜진다
- 업데이트 창이 안 뜨면 **바탕화면 VidShelf 아이콘**이나 폴더 안의 **`VidShelf 실행.cmd`**로 켜면 된다. 새 버전이 있으면 알아서 빌드한 뒤 켜진다
- 지금 버전은 설정 → 데이터에 `버전 0.2.0 (커밋)`으로 나온다

동작 방식: `scripts/launch.cjs`가 마지막으로 빌드한 커밋을 `.git/vidshelf-built.json`에 기억하고, 커밋이 바뀌면 다시 빌드한다. 구성 요소(package-lock.json)가 바뀌었을 때만 `npm ci`로 다시 설치한다(이때는 VidShelf를 잠깐 닫는다). Pull 직후 자동 실행은 `scripts/hooks/post-merge`를 `.git/hooks`에 복사해서 연결한다.

### 개발

```bat
git clone https://github.com/RolTheDice/vidshelf-app.git
cd vidshelf-app
npm ci
npm start
```

`npm start`는 화면을 빌드하고 프로그램을 실행한다. 코드를 고치면서 쓸 때는 `npm run dev` (화면 수정이 바로 반영됨). 테스트는 `npm test`.

설치 파일은 `npm run dist:win`으로 만들면 `release\VidShelf-Setup-<버전>.exe`가 생긴다. GitHub에서는 `main`에 올릴 때마다 **Actions → build**가 설치 파일을 만들고, 공개 저장소면 Releases에도 올린다.

## 사용 순서

1. **폴더 추가** — 영상이 있는 폴더를 고른다. 하위 폴더까지 읽고, 목록만 기억한다. 영상 파일이나 폴더를 창에 **끌어다 놓아도** 추가되고, 새로 들어온 영상은 바로 정보 받기가 시작된다.
2. **정리하기** → **새 영상 정리**
   - 먼저 등록한 폴더를 다시 읽어서 새로 넣은 파일을 찾는다 (프로그램을 켤 때도 자동으로 읽음)
   - 품번 읽기 → r18.dev 정보 → (처음 보는 배우만) 품번기 한국어 이름 → 표지 받기 순서로 진행
   - r18.dev에 없는 작품은 품번기에서 찾는다
   - 영상 3개를 동시에 처리하되, 사이트마다 요청은 하나씩 쉬면서 묻는다 (r18.dev 0.25초, 구글 번역 0.5초, 품번기 1.5초 이상)
   - 이미 정리한 영상은 건너뛴다. 같은 품번이 이미 정리돼 있으면 사이트에 다시 묻지 않고 그 정보를 쓴다
   - 정보를 못 찾은 영상은 다음 정리 때 다시 시도하지 않는다 → **못 찾은 것 다시 시도**로 따로 실행
   - 처음부터 다시 받으려면 **전체 다시 받기**
   - 파일 이름을 바꾸거나 다른 폴더로 옮겨도 (크기와 품번이 같으면) 정보·별점·재생 횟수가 이어진다
3. 위쪽 칩(배우별, 제작사별 …)으로 분류를 바꿔 본다.

### 키보드

| 곳 | 키 | 동작 |
|---|---|---|
| 목록 | `↑` `↓` / `Enter` / `Delete` | 이동 / 재생 / 삭제 |
| 목록 | `Ctrl+클릭` `Shift+클릭` `Ctrl+A` | 여러 개 선택 |
| 플레이어 | `Space` | 재생·일시정지 |
| 플레이어 | `←` `→` (Shift: 1분) | 10초 이동 |
| 플레이어 | `↑` `↓` / `M` | 볼륨 / 음소거 |
| 플레이어 | `L` | 소리 크기 자동 맞춤 켜기·끄기 |
| 플레이어 | `C` / `,` `.` | 자막 켜기·끄기 / 자막 0.5초 빠르게·늦게 |
| 플레이어 | `F` (또는 더블클릭) | 전체 화면 |
| 플레이어 | `T` | 넓게 보기 (양옆 목록 숨기기) |
| 플레이어 | `N` `P` | 다음 / 이전 영상 |
| 재생 중 어디서든 | 숫자 키패드 `3` / `1` | 다음 / 이전 영상 |

재생 화면 크기: 표지·재생 창과 양옆 목록 사이의 경계선을 끌어서 조절한다 (크기는 기억됨). 플레이어의 **넓게 보기** 버튼이나 `T`로 양옆 목록을 숨길 수 있다.

배우 이름 지우기: 배우별 목록에서 이름에 마우스를 올리면 나오는 ✕, 또는 배우 화면 카드의 ✕. 그 배우가 들어간 영상의 출연 정보에서 이름만 빠진다. "다시 받아도 넣지 않기"를 켜 두면 설정 → 지운 배우 이름에서 다시 허용할 수 있다.

재생 횟수는 내장 플레이어에서 실제로 본 시간이 합쳐서 40초 이상(짧은 영상은 절반 이상)이면 1회로 센다. 건너뛴 시간은 빼고, 보다 만 시간은 다음에 열었을 때 이어서 더한다. 한 번 열었을 때는 최대 1회. 정보 화면의 `−1` `+1`로 직접 고칠 수도 있다.

자막: 영상과 같은 폴더에 이름이 같은 자막 파일(`ABC-123.smi`, `ABC-123.srt`, `ABC-123.ko.srt`, `.ass`, `.vtt`)이 있으면 내장 플레이어가 자동으로 띄운다. 한국어 자막(CP949/EUC-KR)도 읽는다. 자막이 있는 영상은 목록에 `자막` 표시가 붙는다. 내장 플레이어는 mp4(H.264)·webm을 재생한다. 재생이 안 되는 파일은 "기본 플레이어로 열기"를 누르면 된다.

### 표지 저장 위치 (설정)

| 방식 | 저장 위치 |
|---|---|
| 프로그램 폴더에 저장 (기본) | `%APPDATA%\VidShelf\covers\ABC-123.jpg` |
| 영상 옆에 저장 | `D:\영상\ABC-123.jpg` |
| covers 폴더에 저장 | `D:\영상\covers\ABC-123.jpg` |

어느 방식으로 저장했든 이미 있는 표지는 다시 받지 않고 그대로 인식한다. 같은 이름의 파일이 이미 있으면 덮어쓰지 않는다.
저장 위치를 바꾼 뒤 **이미 받은 표지를 이 위치로 옮기기**를 누르면 기존 표지도 한 번에 옮긴다 (이 프로그램이 만든 `품번.jpg`만 옮기고, 직접 넣은 다른 이름의 이미지는 그대로 둔다).

배우별·제작사별 등에서 **정보 받기 전**(아직 시도 안 함)이나 **정보 못 찾음** 묶음을 고르면 위에 **이 N개 정보 받기** 버튼이 나온다. 여러 개 선택한 뒤 **정보 받기**를 눌러도 된다.

### 정보를 못 읽게 됐을 때

- r18.dev: 화면이 아니라 JSON을 읽어서 잘 깨지지 않는다. 응답 모양이 바뀌면 `electron/r18.cjs`의 `parseCombined`만 고치면 된다.
- 품번기: 상세 페이지를 `Ctrl+S`로 저장해 `tests/fixtures/`에 넣고, `electron/poomki-extract.cjs`의 규칙을 고친 뒤 `npm test`.

### 표지를 못 찾는 레이블이 있을 때

표지는 ① 이 PC에서 배운 규칙 → ② ShowCover v1.1 대응표(`electron/showcover.cjs`) → ③ 흔한 형태 순서로 찾고, 찾을 때마다 레이블별 규칙을 배운다 (설정 → 표지 찾기 규칙에서 확인).
처음 보는 특이한 레이블은 그 레이블 작품 하나의 실제 표지 주소(`https://pics.dmm.co.jp/…pl.jpg`)를 설정 → 표지 찾기 규칙에 품번과 함께 넣으면, 같은 레이블은 그 형태부터 찾는다.

## 알아둘 점

- avdbs는 자동 수집(크롤링)을 금지하고 영구 차단을 공지해서, avdbs 기능은 없앴다.
- 개인 사용 목적의 비공식 프로그램이며 r18.dev·품번기·DMM과 관계가 없다. 각 사이트의 이용약관상 자동 수집이 제한될 수 있고 계정 제재 가능성이 있으니, 각자 책임 아래 쓰고 요청 간격(설정)을 너무 줄이지 말 것.
- 이 프로그램은 영상·표지·정보를 배포하지 않는다. 사용자가 자기 PC의 파일을 정리할 때 사이트에서 정보를 받아 올 뿐이다.
- 정리한 정보는 전부 내 PC(`%APPDATA%\VidShelf`)에만 저장되고, 어디로도 보내지 않는다.
- 제목은 일본어 원제를 한국어로 번역해서 저장하고 (설정에 DeepL API 키를 넣으면 DeepL, 없으면 키 없이 쓰는 구글 번역), 원제는 그 아래에 작게 나온다. 기계 번역이라 어색할 수 있고, 구글이 막으면 영어 제목으로 두었다가 다음 정리 때 다시 번역한다 (설정에서 끌 수 있음). 줄거리는 없다.
- 예전에 avdbs로 받아 둔 정보(한국어 제목·제작사 등)는 그대로 남는다. 새 작품의 제작사·레이블은 같은 품번 앞글자로 예전에 받은 한국어 이름이 있으면 그 이름을 쓴다.
- FC2, 숫자형 품번(`123456-789`)은 아직 인식하지 않는다.
